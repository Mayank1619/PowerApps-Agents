# MCP Approval Checklist

Complete this review independently before registering or enabling an MCP server. A public Microsoft/GitHub source does not establish organization approval.

| Review area | Evidence required | Result |
| --- | --- | --- |
| Publisher | Verified publisher identity and contact | Pending |
| Source repository | Official repository URL, ownership, release process | Pending |
| License | License/EULA and redistribution/use obligations | Pending |
| Package integrity | Exact artifact/version, signatures/checksums, dependency/SBOM review | Pending |
| Authentication | Delegated/app identity, token handling, cache location, logout/disable procedure | Pending |
| Permissions | Exact scopes/roles, least-privilege rationale, consent owner | Pending |
| Tools exposed | Complete list, schemas, data returned, hidden/tool-discovery behavior | Pending |
| Write operations | Create/update/delete/publish/share/run capabilities and technical restriction method | Pending |
| Logging | Log paths, fields, access, retention, redaction, correlation IDs | Pending |
| Telemetry | Default state, collected fields, destinations, opt-out and policy | Pending |
| Network endpoints | Hosts, protocols, outbound destinations, token audience | Pending |
| Data retention | Server/client retention, caches, backups, prompt/context flow | Pending |
| Vulnerability management | Advisories, patch cadence, dependency scanning, response SLA | Pending |
| Ownership | Business, technical, security, and service owners | Pending |
| Support | Escalation channel and operational support model | Pending |
| Rollback | Reversibility, data recovery, prior versions, approver | Pending |
| Disablement | Verified local/remote shutdown and permission revocation owners | Pending |
| Environment restriction | Development allowlist and production deny mechanism | Pending |
| Independent QA | Reviewer, test evidence, residual-risk acceptance | Pending |

Do not enable the server while any mandatory review is pending or when destructive tools cannot be technically excluded from a read-only session.
