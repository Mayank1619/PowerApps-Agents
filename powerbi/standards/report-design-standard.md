# Report Design Standard

Status: proposed; validate accessibility and rendering in the approved Power BI authoring environment.

For every page document its purpose, target persona, key questions, measures, filters, and interaction behavior. Select visuals for analytical intent and avoid unsupported claims, misleading axes, overcrowding, and ambiguous totals.

- Use meaningful titles and dynamic subtitles only when their filter context is clear.
- Make relevant filters visible and explain which visuals they affect; define slicer, drill-through, tooltip, bookmark, and navigation behavior.
- Provide alt text, accessible contrast, non-color-only signals, keyboard/navigation considerations, and a considered reading order.
- Check consistent layout, text legibility, mobile layout, and responsive behavior.
- Design useful empty, loading, and error states.
- Link metric definitions or guidance where needed; every metric must trace to an approved requirement and existing measure.
- Record accessibility/performance validation evidence and known gaps; do not claim conformance without evidence.
